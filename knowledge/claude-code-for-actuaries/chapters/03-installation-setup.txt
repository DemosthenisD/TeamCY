 CHAPTER 3

 Installation and Setup

 3.1 Prerequisites
     • Subscription: an active Claude subscription (Claude Pro, about $20/month, is enough to start; no
     API key required).
     • A computer: Mac, Windows or Linux, able to run the Claude Desktop app.
     • Internet: a stable connection.
     • Skills: none beyond your actuarial work. No terminal, no package manager, no system
     administration.


   Note: There are numerous ways to access Claude Code, with pricing linked to fixed-cost plans with usage
   limits or variable-cost plans (API access) without limits. The fixed-cost subscription is the simplest way to
   start; API access suits intensive or automated workloads.



 3.2 Installation in Three Steps
 Step 1 — Download the Claude Desktop app. Go to claude.ai/download and install the application for
 your operating system (Mac, Windows or Linux).

 Step 2 — Create an account and subscribe. Sign up with your email address and subscribe to Claude
 Pro ($20/month).

 Step 3 — Start working. Open Claude Code from the app, point it to your project folder (the working
 directory), and type your first instruction. That's it.


   Note: A second installation path exists: a command-line install through npm and Node.js, aimed at
   developers. It is not needed here: the desktop app ships with everything included, which matters in corporate
   environments where installing developer tooling is restricted.



 3.3 Security Settings Before You Start
 Before pointing Claude Code at anything, two reflexes. The first is scoping: give it access to the project
 folder only, never to a drive or folder tree holding documents you do not intend to share with the tool —
 the trust dialog shown in section 3.7 enforces exactly this. The second is deciding what may be done with
 your conversations. On individual plans, one setting controls whether your chats and coding sessions can
 be used to train Anthropic's models. Here is how to review it and turn it off:

 1. Open the account menu at the bottom left of the app and click Settings.

 3.4 A Tour of the Interface
 Five elements are worth knowing before your first real project:

     • The chat zone: where you converse with the agent in natural language. Instructions, follow-ups,
     corrections: everything goes through here.
     • Models: several models are available, from the fastest and cheapest to the most capable. As a rule
     of thumb: use a mid-tier model for most actuarial work, and reserve the top tier for complex
     architecture or subtle reasoning. Model names evolve; the fast/balanced/powerful tiering remains.
     • Effort level: controls how deeply the model thinks before answering. Raise it for complex modeling
     questions, keep it standard for routine tasks.
     • Context window: how much of your project Claude can hold in mind at once. Large models read
     hundreds of pages; structure your project so the relevant files are easy to find.

 3.5 The CLAUDE.md File
 This is the most important file of your setup. Claude Code reads it automatically at the start of every
 session. It contains your project context, your technical stack, your conventions and your business rules.
 Well written, it saves you from repeating the same instructions and dramatically improves the quality of
 the results.

 Think of it as the briefing document you would hand a new analyst joining your team: where the data lives,
 which tools to use, which rules to follow, what never to do. A complete CLAUDE.md template for actuaries
 is provided in the appendix (chapter 12).


   Tip: Keep your CLAUDE.md under 200 lines. Claude Code re-reads it constantly; a bloated file dilutes the
   signal. Treat it as an index that points to detailed files, not as a manual.



 3.6 Connecting to Your Data with MCP
 MCP (Model Context Protocol) is a standard that lets Claude Code plug directly into your data sources
 instead of going through manual exports. Concretely, it is a connector: once configured, Claude Code can
 query a local SQL database, an Excel workbook, a document repository or an internal API, at the source.

 Instead of hand-exporting a CSV of your portfolio to give to Claude Code, you configure the connector
 once, and Claude Code queries the data directly. For an actuary, this means a dashboard or a monitoring
 tool that reads live data, with no intermediate manipulation.


   Tip: Start simple: a well-written CLAUDE.md already delivers 80% of the value. MCP configuration comes
   later, when you want to industrialize data access.



 3.7 Running a Companion Pack End to End
 Every companion pack of this guide (the table in chapter 1) runs with the same routine. This walkthrough
 uses the bond valuation library pack as the example; the steps are identical for the other nine — and for
 your own projects, since a pack is nothing more than a ready-made working folder.

 Step 1 — Create the working folder on your computer
 Download the pack from its Drive link into a dedicated folder on your machine. It already holds everything
 the session needs: the data in data/, the CLAUDE.md, and the PROMPT.md. For a project of your own,
 this is the step where you gather every resource that is useful and relevant: documentation, data extracts,
 existing code.

 Step 4 — Pick the model and the effort level
 The selector at the bottom right of the input bar sets the model and the effort level for the session. The
 trade-off is capability against speed and cost: the largest models reason deepest on long, ambiguous
 pipelines; lighter models are faster and cheaper and handle well-specified tasks very well; the effort
 setting tunes how long the model thinks before it acts. There is no single right choice — it depends on the
 task, and the right reflex is to experiment. For a first run of a pack, the defaults are fine.
