# TeamCY

Streamlit invoice app (`Invoice_Test_v1_app.py`) plus a knowledge base for actuarial work.

## Actuarial knowledge base
`knowledge/claude-code-for-actuaries/` holds "Claude Code for Actuaries — The Complete Guide" (PDF, full text, per-chapter text, use-case catalog, companion-pack links, CLAUDE.md template).
- For actuarial tasks use the `actuarial-guide` skill or the `actuarial-analyst` agent; read `README.md` there first, then only the needed chapter in `chapters/`.
- Rules from the guide: synthetic data only unless approved, no secrets in code/prompts, tests alongside code, architecture before large modules, flag items needing actuarial validation.
